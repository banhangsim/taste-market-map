# 취향마켓 · 주변에 가볼만한 곳

반항심과 셀러들의 취향가득 동네 소개. 2026년 10월 25일 취향마켓 현장용 인쇄 지도와 모바일 지도입니다.

- 웹: https://banhangsim.github.io/taste-market-map/
- 33개 실제 장소, 32개 번호. 피터팬 본점과 원천교회점은 같은 06번입니다.
- 카페·간식 / 식사·술집 / 볼거리·산책 분류, 검색, 확대·이동, 장소별 카카오맵 링크.
- 데이터 확인일 2026-10-20. 방문 전 실제 영업시간을 확인해 주세요.

## 인쇄

`downloads/taste-market-brochure-A4-duplex.pdf`: A4 가로, 1-2쪽 양면, **짧은 변 넘김**, 실제 크기 **100%**, 한 면에 한 페이지. 소책자/모아찍기/용지에 맞춤 옵션은 끕니다.

지도면(2쪽)을 위로 두면 왼쪽부터 100 / 100 / 97 mm입니다. **오른쪽 97 mm 면을 왼쪽으로 먼저 접고, 왼쪽 100 mm 면을 오른쪽으로 덮습니다.** 접은 크기는 약 100 × 210 mm입니다. 지도면 기준 접는 선은 왼쪽에서 100, 200 mm, 겉면에서는 97, 197 mm입니다.

먹 K + 별색 `BANHANGSIM SKY BLUE`의 2도 PDF입니다. 흰 여백 설계로 도련은 없고, 접지선·재단선은 인쇄물에 표시하지 않았습니다. PDF는 글꼴을 포함하며 자동 축소 방지/짧은 변 넘김 설정을 저장했습니다. 프린터 설정에서도 확인하고 1부를 먼저 시험 인쇄하세요.

- `downloads/print-and-fold-guide-A4.pdf`: 인쇄·접기 안내 1쪽, 단면 인쇄
- `downloads/mobile-map-QR-sign-A4.pdf`: 현장 비치용 QR 안내문 1쪽, 단면 인쇄
- `assets/map-qr.svg`: 모바일 지도 QR 원본

## 수정과 배포

별도 빌드나 API 키 없이 동작하는 정적 HTML/CSS/JavaScript 사이트입니다. GitHub Pages가 `main` 브랜치의 루트 폴더를 게시합니다.

장소 정보는 `assets/places.json`에 있습니다. 각 장소의 `no`는 인쇄물 번호와 같고, `map_id`는 고유 식별자입니다. 원래 지도와 위치가 함께 움직이므로 장소 좌표/이름을 바꿀 때는 지도 이미지와 표시 영역(`map_label_box`)도 함께 갱신해야 합니다. 원래 축소 지도는 인쇄본과 같은 연희동 인셋입니다.

사이트는 외부 지도 SDK, 분석 추적, 위치 권한을 사용하지 않습니다. 카카오맵 링크는 사용자가 누를 때만 열립니다. 인쇄물 링크도 보존했습니다.
